# Integración en los Procesos de Negocio (BPM) · Actividades

Sitio estático de la asignatura (UNIR, Máster en Gestión por Procesos para la Transformación Digital). Se genera con `build_site.py`; no editar `index.html` a mano.

- `index.html` — dashboard de actividades (PWA, funciona sin conexión una vez abierta).
- `a1/` — ficheros de la Actividad 1.
- `reto-ibericos/` — reto de clase 1.

Material docente de uso exclusivo para los estudiantes de la asignatura.
